# RUNFEST DidWell

https://runfest.didwell.no/

Program and public EQ Timing start lists/results for 3 October 2026, and a daily Sandnes hourly weather table via Open-Meteo.

Results refresh through GitHub Actions every five minutes on the event day, plus a follow-up on 4 October. The browser reads the runfest-data branch, with an initial snapshot as fallback. Collection is date-limited to this event.

Source: https://www.runfestnorway.com/no/runners-info and https://live.eqtiming.com/80878
